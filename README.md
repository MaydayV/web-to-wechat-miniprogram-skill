# Web to WeChat Mini Program Skill

将工具网站作为产品研究来源，分层提炼用户需求和核心功能，再实现视觉、文案与内容原创的微信小程序原生版本。

## 内容

- `SKILL.md`：Skill 入口和执行边界。
- `references/url-to-miniprogram-workflow.md`：静态优先的网站盘点、WXML 映射、脚手架、API 与 DevTools 验证流程。
- `references/source-analysis.md`：融合来源和设计取舍记录；只含来源链接与摘要，不包含来源仓库副本。

所有页面使用小程序原生技术实现，不将来源网站嵌入 WebView，也不复制其专有内容或视觉风格。
